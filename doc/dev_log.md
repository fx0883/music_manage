# 诗词学习APP开发日志

## 项目概述
- 项目名称:诗词学习APP
- 后端框架:Django + DRF
- 前端框架:UniApp + Vue 3
- 开发语言:Python(后端), JavaScript/TypeScript(前端)
- 数据库:MySQL
- 缓存:Redis
