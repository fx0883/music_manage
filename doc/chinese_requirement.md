# 项目需求
需要开发一款教外国人学习中国古诗词的app，后端系统使用Django开发。主要功能如下：

1. **古诗词浏览功能**
    - 外国人可浏览古诗词，古诗词每句中每个字都要有拼音、中文注释、译文和赏析。
    - 同时要有各国语言的注释、译文和赏析，但每次仅显示当前所选外语对应的内容，不显示所有外语信息。
    - 支持多种字体切换，提供不同书法风格的展示效果。
    - 支持左右滑动切换诗词。

2. **古诗词排序功能**
    - 古诗词可根据难易程度排序。
    - 支持按朝代、作者、主题等多维度排序。
    - 提供搜索功能，支持按标题、作者、内容检索。

3. **背诵功能**
    - 有背诵古诗词的功能，背诵时会随机出题。
    - 题目是从古诗词中抽取一句话或几个汉字，让使用者填空。
    - 提供多种游戏模式：填空题、选择题等。
    - 可以根据用户的学习进度自动调整难度。

4. **作者信息展示功能**
    - 每个古诗词都要展示其作者的信息和图片，还有创作背景。
    - 作者信息支持多语言显示。
    - 提供作者相关作品的关联展示。

# 技术要求

## 后端要求
1. **框架与数据库**
    - 使用Django + Django REST framework开发

2. **数据处理**
    - 支持批量导入导出诗词数据
    - 支持多语言内容的管理
    - 提供字体文件管理功能

3. **性能要求**
    - API响应时间控制在500ms以内
    - 支持数据缓存
    - 支持大量并发访问

## 前端要求
1. **技术框架**
    - 使用UniApp + Vue 3开发
    - 采用组合式API编程
    - 使用Pinia进行状态管理

2. **UI要求**
    - 支持自定义字体加载
    - 实现流畅的滑动切换效果
    - 提供良好的加载状态提示
    - 适配不同尺寸的移动设备

3. **用户体验**
    - 支持离线访问基本功能
    - 提供友好的错误提示
    - 实现平滑的页面切换动画
